<h2 align="center">⚡ Featured project</h2>

<h3><a href="https://github.com/GitV1KO/mnist-c6416-linear-asm">MNIST on a C6416 DSP</a></h3>

A course project that runs handwritten-digit recognition on a **TI TMS320C6416 / C64x** board without an operating system. Based on an existing CNN project, I added a **TI linear assembly** dot-product kernel and compared it with C using the CCS Clock.

<p>
  <img src="https://img.shields.io/badge/C-00599C?style=flat-square&amp;logo=c&amp;logoColor=white" alt="C" />
  <img src="https://img.shields.io/badge/TI_C64x-Linear_Assembly-0891B2?style=flat-square" alt="TI C64x linear assembly" />
  <img src="https://img.shields.io/badge/Runtime-Bare_Metal-334155?style=flat-square" alt="Bare-metal runtime" />
  <img src="https://img.shields.io/badge/IDE-CCS_3.1-2563EB?style=flat-square" alt="CCS 3.1" />
</p>

| On-board check | Observed result |
| :--- | :--- |
| Digit recognition | 19 correct predictions out of 20 test images |
| 128-element dot product, C → linear ASM | 92 → 61 CPU cycles, about **1.51×** faster |

<sub>The cycle counts are from one CCS Clock comparison in the Debug build, using the same input. They describe the dot-product call, not the entire CNN. The repository includes the original project attribution and measurement details.</sub>
